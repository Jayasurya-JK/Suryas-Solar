# New landing page

Load `suryas-business-facts` first. Ask the owner for anything local you don't know (real installs in that town, distance/visit days, local roof types) - local proof is what makes these pages rank; generic text gets "Crawled - currently not indexed".

## A. Service-area town page
1. Add an entry to `src/lib/locationsData.js` copying the shape of the existing ones: `name`, `title` (keyword first, <= 60 chars, e.g. "Solar Panel Installation in Chidambaram | Surya's Solar"), `description` (150-160 chars), `heroTitle`, `heroSubtitle`, 3 specific `localInsights`, `mapEmbed` (Google Maps `q=<lat>,<lng>` embed), `popularSystems`.
2. The page is generated by `src/pages/service-areas/[city].jsx` via `getStaticPaths` - no new page file needed. Key = URL slug (lowercase, hyphens).
3. Add `{ url: '/service-areas/<slug>', changefreq: 'monthly', priority: 0.8 }` to `serviceAreaPages` in `scripts/generate-sitemap.js`.
4. Link to it: Header/Footer "Locations" menus (`src/components/Header.jsx`, `Footer.jsx`), and from 2-3 relevant blog posts.
5. Add the town to "Service areas" in the `suryas-business-facts` skill and to `public/llms.txt`.

## B. System-size page
1. Copy `src/pages/systems/3kw-solar-system-with-subsidy.jsx` to the new slug; edit the `SYSTEM` constant (prices, subsidy, bill range, units/day) using only owner-confirmed numbers. Subsidy: 1kW ₹30,000, 2kW ₹60,000, 3kW+ ₹78,000; commercial systems get no PM Surya Ghar subsidy.
2. Update `<title>`, meta description, canonical `https://www.suryassolar.com/systems/<slug>`, OG tags, FAQ JSON-LD.
3. Add to `systemPages` in `scripts/generate-sitemap.js`, the Header "Solar Systems" menu, and the Keyword Intent Map in `BLOG-AUTHORING.md`.
4. Update `getRelatedLinks()` in `src/pages/blog/[slug].jsx` if posts mentioning that size should link to it.

## Finish
`npm run build`, open `http://localhost:3000/<path>` with `npm run dev` to eyeball mobile + desktop, then `ship-site`.
